# Murugesan Balasubramanian — Personal Portfolio

A responsive React + Vite portfolio inspired by the supplied website screenshots. It uses a warm ivory / indigo editorial design, scroll-reveal motion, responsive navigation, project cards, skills, and an ElvOra future-idea section.

## Run locally

1. Install Node.js (LTS).
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local URL shown in the terminal.
4. To create a production build, run `npm run build`.

## Before publishing

- Replace `hello@example.com` in `src/App.tsx` with the email address you want to publish.
- Confirm your GitHub URL in the contact section.
- Add actual project/demo links when available. Project descriptions intentionally avoid claiming unfinished projects are complete.
- The homepage portrait uses `public/images/murugesan-portrait.png` from the uploaded original photo.

The supplied original portrait is retained; it has not been regenerated.
